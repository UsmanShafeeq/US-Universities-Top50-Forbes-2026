# US Universities Top 50 (Forbes 2026) – Data Analysis & Visualization

This repository contains a **comprehensive analysis of the Top 50 Universities in the U.S. (Forbes 2026)** using Python, Pandas, Matplotlib, Seaborn, and Plotly. The project focuses on multiple metrics such as **research impact, international student ratio, employment rate**, and other key factors.

## 📌 Problem Statement
The goal of this project is to analyze and visualize the top 50 U.S. universities based on key performance metrics, providing insights beyond simple ranking positions. This helps students, educators, and policymakers make **data-driven decisions** about higher education.

## 🛠 Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Interactive and static visualizations
- Correlation analysis between key metrics
- Geographic and historical trend analysis
- Insights and recommendations for prospective students

## 📊 Key Metrics Analyzed
- **Research Impact Score** – institutional research influence
- **International Student Ratio** – global diversity
- **Employment Rate** – graduate career outcomes
- **Institution Type, State, Founded Year** – demographics and history

## 📈 Visualizations
- Bar charts for research impact and state distribution
- Scatter plots for employment vs international student ratio
- Heatmaps for correlation analysis
- Histograms for founding year distribution
- Interactive Plotly visualizations
